MultiExplorer 1.6.4
Release date: 18 September 2026

Highlights
----------

- Added separate file and folder totals to the status bar for each pane's active tab.
- Local item totals now update from filesystem notifications, with debouncing and a
  single-flight worker to keep large folders responsive during bursts of changes.
- Added a periodic recovery refresh for missed filesystem notifications while avoiding
  redundant recounts during navigation, view changes and file operations.
- Network locations are no longer enumerated for item totals, avoiding slow or blocked
  scans of UNC shares and mapped network drives.
- Added F1 as an application-wide shortcut for opening MultiExplorer Help.
- Help now falls back to an embedded offline copy if MultiExplorer.Help.html is deleted.
- Added right-aligned selected file/folder counts and a total size to each pane's
  status bar, including cancellable recursive sizing for selected folders and
  decimal storage units.
- Fixed toolbar view-mode commands so List, Tiles, icon and Content views replace
  the responsive Details view immediately.
- Promoted responsive Details to the standard Details mode and removed its
  experimental View > Show toggle and obsolete persisted setting.
- Made Compact view, item check boxes, file-name extension visibility and hidden
  items independent per-tab options that do not modify Windows File Explorer or
  other MultiExplorer tabs.
- Replaced the legacy Explorer command band's mixed light/dark rendering with a
  fully dark, DPI-aware command band that retains its common actions in dark mode.
- Fixed Shell context menus whose action header was dark while the remaining menu
  rows, separators and icon gutter stayed light.
- Added active-pane shortcuts: Ctrl+Shift+N creates a folder and starts inline
  rename, while Ctrl+N and Ctrl+T open a new tab.
- Setup now detects foreground and tray-hidden MultiExplorer instances before the
  progress phase and offers to close the running instance before continuing.
- Release builds now stamp application binaries with a monotonic build file version,
  ensuring rebuilt installers carrying the same displayed version replace old code.

Installation notes
------------------

- Application settings and saved panel state are preserved during upgrades.
- MultiExplorer is a per-user installation and includes its required .NET runtime.
- The start-with-Windows option is disabled by default and can be changed at any time
  from either pane's More (...) menu.
