MultiExplorer 1.5.9
Release date: 15 September 2026

Highlights
----------

- Added a per-user "Start MultiExplorer with Windows" option to the More (...)
  menu in both explorer panes.
- Windows sign-in launches now start MultiExplorer quietly in the system tray.
- Added a Windows notification confirming that MultiExplorer started in the tray;
  clicking the notification or tray icon opens the application.
- Startup registration automatically follows the installed executable location and
  does not require administrator rights.
- Improved single-instance handling so a Windows startup invocation does not bring
  an already-running MultiExplorer window to the foreground.
- Corrected the initial vertical splitter position for existing installations while
  continuing to preserve later user adjustments.
- Corrected installer upgrade detection so a normal upgrade from an older release no
  longer displays the downgrade/reinstall warning.
- Added a built-in offline Help page, available from More (...) > Help in either
  explorer pane. It includes an overview, getting-started guidance, file-management
  instructions, view options, filtering, keyboard shortcuts, and background-operation
  information.
- Clarified that QuickLook is a separate third-party application and added a link to
  its GitHub page from the Help page.
- Reorganised the More (...) menu with clearer labels for Explorer options, appearance,
  hotkey, auto-start, logs, Help, About, and Exit.
- Improved settings reliability by saving preferences atomically, protecting the last
  valid settings file if the application stops during a save.
- Background file operations now remove temporary request and cancellation records when
  they finish. Completed, failed, and cancelled status records are retained for up to
  24 hours, and interrupted helper operations are recorded as failures for recovery.

Installation notes
------------------

- Application settings and saved panel state are preserved during upgrades.
- MultiExplorer is a per-user installation and includes its required .NET runtime.
- The start-with-Windows option is disabled by default and can be changed at any time
  from either pane's More (...) menu.
