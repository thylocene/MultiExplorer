What is MultiExplorer?

MultiExplorer is a dual-pane Windows file manager. It places two independent native Windows Explorer views in one window, so you can browse separate locations and work with files between them without opening extra Explorer windows.

Use it to organise, copy, move, rename, preview, and delete files and folders. It uses the familiar Windows shell for file icons, thumbnails, context menus, and file associations.

Get started

MultiExplorer has two independent file panes. Use them to browse different locations, then copy or move items between them. Drag the centre splitter to resize the panes, or use its arrows to temporarily collapse one pane.

Tabs

Each pane has its own tabs. Click + to open another tab, click a tab to switch to it, and click × to close it. Drop a dragged tab anywhere in its own pane to duplicate it at the end, like pressing Ctrl+T; the floating preview says "Duplicate in current pane". Drop it anywhere on the other pane to move it there; the floating preview says "Move tab to other pane". Hold Ctrl while dragging a tab to the other pane to copy it instead; the source tab stays in place and the preview says "Copy tab to other pane". Moving the only tab out of a pane opens a new tab at C:\ in the source pane.

In Settings, you can enable opening a tab in Windows File Explorer by dropping it outside MultiExplorer. File Explorer opens on the screen where you release it, then the MultiExplorer tab closes. The last tab in a pane cannot be dropped on the desktop, so that drag shows only the blocked cursor and no floating preview; it can still be duplicated within its pane or moved or copied into the other pane.

Address bar

Click a breadcrumb segment to go to that folder. Click a chevron between segments to choose an immediate subfolder. Press F4 or click empty space in the address bar to type a path directly. Press Enter to navigate or Esc to cancel.

You can enter normal paths, UNC paths such as \\server\share, and paths containing environment variables such as %USERPROFILE%.

Manage files

Use the toolbar, standard Windows shortcuts, right-click menus, or drag and drop. The file lists use the Windows shell, so familiar file associations, thumbnails, and context-menu extensions remain available.

  • New folder: click New folder or press Ctrl + Shift + N. The new folder is selected and ready to rename.
  • Copy or move: use cut/copy and paste, or drag files into the other pane. A same-drive drag normally moves files; holding Ctrl copies and holding Shift moves.
  • Copy as path (Ctrl+Shift+C): place the selected file and folder paths on the clipboard, one per line.
  • Create shortcut: right-click one file or folder and choose Create shortcut.... Choose a Windows shortcut (.lnk), a file hard link, or a symlink, then place it in the current folder, its parent, the Desktop, or the other browser pane. Hard links require the same volume; symlinks may require Windows Developer Mode or permission.
  • Delete: press Del to send items to the Recycle Bin, or Shift + Del for a permanent delete.

Compare the two panes

Open View → Compare panes... to scan the active left and right folders, including subfolders. The results show missing items, newer files, size differences, and file/folder conflicts. Every result starts with Skip; choose individual copy or delete actions, or use Select suggested copies for missing and newer items.

Click Review actions... to see every selected source and destination before starting background operations. A changed folder requires a new comparison. The scan compares size and modified time, not file contents; links are listed but cannot be synchronized. Network locations are scanned only when you open this command, and deleting from a network share may be permanent.

Views and panes

Open View ▾ on the toolbar to choose the responsive Details view, List, Tiles, icon sizes, or Content view. MultiExplorer remembers the view mode and icon size separately for each folder, so returning to a folder restores its previous presentation. The same menu can show or hide the optional Details and Preview panes.

  • Details pane: shows the selected item's icon, type, size, and modified date.
  • Preview pane: uses the Windows preview handler registered for the selected file type, when available. Drag the vertical divider at the preview pane's left edge to resize it. The left and right explorer panes remember their preview widths independently.
  • Status bar: shows file and folder totals on the left and the number and combined size of selected files and folders on the right. Selected-folder contents contribute to the size but not the top-level selection count. Sizes use decimal storage units, where 1 KB is 1,000 bytes. Selection details are not calculated for network locations.
  • Show submenu: controls the navigation pane, compact view, item check boxes, filename extensions, and hidden items for the active tab only.
  • Quick access: opening a pinned folder in the navigation pane shows it in the active MultiExplorer tab.
  • QuickLook preview: if QuickLook is installed and enabled, press Space on a selected file to preview it.

QuickLook is a separate third-party application. It is not included with, or developed as part of, MultiExplorer. Learn more or download it from the QuickLook GitHub page.

Compact view, item check boxes, filename extensions, and hidden items are retained independently by each tab for the current MultiExplorer session. They do not change Windows File Explorer or another tab.

The row directly below MultiExplorer's command bar is called the Explorer command band. Windows supplies it in Light mode; MultiExplorer uses a fully dark replacement with the common commands in Dark mode.

Find items in the current folder

With a file list active, just start typing. MultiExplorer opens a Contains filter for the current folder and shows matching folders first, then matching files. The filtered list keeps the columns and their order from the active file view, including network tabs; scroll horizontally to see columns beyond the pane width.

To copy or move selected files and folders to the other pane's current folder, press Alt + C or Alt + M. Both actions are also available in the selected items' right-click menu.

  • Press Enter or double-click a result to open it.
  • Select a result and press F2 to rename the file or folder in the filtered list.
  • Click a column header to sort the results; click it again to reverse the order. Folders stay above files.
  • Press Backspace to remove the last filter character.
  • Press Esc or click × to clear the filter.
  • Right-click a result for its standard Windows context menu.

The … ▾ menu

Click … ▾ at the far right of either toolbar for application-wide commands:

  • Settings: configure Explorer options, deletion confirmation, tab drops to Windows File Explorer, appearance, the global hotkey, Auto-start, System Tray behaviour, and QuickLook integration.
  • View logs: open the application log if it exists.
  • Help: open this page.
  • About MultiExplorer: show version and licence information.

Settings file

MultiExplorer stores your preferences, window layout, and saved tab paths in %APPDATA%\MultiExplorer\settings.json. You can paste %APPDATA%\MultiExplorer into the File Explorer address bar to open its folder.

If settings.json does not exist, MultiExplorer starts with default settings. It creates the file when it next saves settings, including when you exit normally.

If the file contains invalid JSON or cannot be read, MultiExplorer also starts with default settings and records the load failure in its log. Loading does not change the file, but a later successful settings save replaces it with the settings used in that session. To recover old values, make a copy of a damaged file before it is overwritten. Then close MultiExplorer, repair the JSON or restore a backup, and reopen the program.

Close MultiExplorer before editing settings.json, and keep a backup copy. Changes made while the program is running may be overwritten by a later save.

Background file operations

Copies, moves, and deletes started from MultiExplorer can continue in the background. If you exit while an operation is active, choose whether to keep it running, wait in the system tray, or cancel it.

For operation progress and recovery, MultiExplorer temporarily stores request and status records under %LOCALAPPDATA%\MultiExplorer\Operations. Completed status records are kept for up to 24 hours; temporary request and cancellation records are removed when the operation ends.
