What is MultiExplorer?

MultiExplorer is a dual-pane Windows file manager. It places two independent native Windows Explorer views in one window, so you can browse separate locations and work with files between them without opening extra Explorer windows.

Use it to organise, copy, move, rename, preview, and delete files and folders. It uses the familiar Windows shell for file icons, thumbnails, context menus, and file associations.

Get started

MultiExplorer has two independent file panes. Use them to browse different locations, then copy or move items between them. Drag the centre splitter to resize the panes, or use its arrows to temporarily collapse one pane.

Tabs

Each pane has its own tabs. Click + to open another tab, click a tab to switch to it, and click × to close it. A pane always keeps at least one tab.

Address bar

Click a breadcrumb segment to go to that folder. Click a chevron between segments to choose an immediate subfolder. Press F4 or click empty space in the address bar to type a path directly. Press Enter to navigate or Esc to cancel.

You can enter normal paths, UNC paths such as \\server\share, and paths containing environment variables such as %USERPROFILE%.

Manage files

Use the toolbar, standard Windows shortcuts, right-click menus, or drag and drop. The file lists use the Windows shell, so familiar file associations, thumbnails, and context-menu extensions remain available.

  • New folder: click New folder or press Ctrl + Shift + N. The new folder is selected and ready to rename.
  • Copy or move: use cut/copy and paste, or drag files into the other pane. A same-drive drag normally moves files; holding Ctrl copies and holding Shift moves.
  • Copy full paths: use the toolbar command to place the selected file and folder paths on the clipboard, one per line.
  • Delete: press Del to send items to the Recycle Bin, or Shift + Del for a permanent delete.

Views and panes

Open View ▾ on the toolbar to choose Details, List, Tiles, icon sizes, or Content view. The same menu can show or hide the optional Details and Preview panes.

  • Details pane: shows the selected item's icon, type, size, and modified date.
  • Preview pane: uses the Windows preview handler registered for the selected file type, when available.
  • Show submenu: controls the navigation pane, compact view, item check boxes, filename extensions, and hidden items.
  • QuickLook preview: if QuickLook is installed and enabled, press Space on a selected file to preview it.

QuickLook is a separate third-party application. It is not included with, or developed as part of, MultiExplorer. Learn more or download it from the QuickLook GitHub page.

File-name extensions, hidden items, and item check boxes use the same Windows settings as File Explorer, so changing them affects Windows Explorer as well.

Find items in the current folder

With a file list active, just start typing. MultiExplorer opens a Contains filter for the current folder and shows matching folders first, then matching files.

  • Press Enter or double-click a result to open it.
  • Press Backspace to remove the last filter character.
  • Press Esc or click × to clear the filter.
  • Right-click a result for its standard Windows context menu.

The … ▾ menu

Click … ▾ at the far right of either toolbar for application-wide commands:

  • Explorer options: open Windows Folder Options.
  • Set appearance: switch between the light and dark application themes.
  • Set hotkey: choose the global shortcut that restores MultiExplorer from the tray.
  • Set Auto-start: run the app when you sign in.
  • View logs: open the application log if it exists.
  • Help: open this page.
  • About MultiExplorer: show version and licence information.

Background file operations

Copies, moves, and deletes started from MultiExplorer can continue in the background. If you exit while an operation is active, choose whether to keep it running, wait in the system tray, or cancel it.

For operation progress and recovery, MultiExplorer temporarily stores request and status records under %LOCALAPPDATA%\MultiExplorer\Operations. Completed status records are kept for up to 24 hours; temporary request and cancellation records are removed when the operation ends.
